# Umbraco Search Manager

A search index manager for the Umbraco backoffice and a drop-in replacement for the built-in
Examine Management dashboard. Work in progress; the full README arrives with the first release.

- Every index at a glance, from core Examine and Umbraco Search.
- Rebuild several indexes at once through a server-side queue, with live status and history.
- Search an index with click-to-filter chips, field suggestions and a validated raw Lucene mode.

Umbraco 17 and 18. MIT licence.
