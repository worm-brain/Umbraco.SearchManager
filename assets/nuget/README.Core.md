# Umbraco Search Manager: Core

Contracts and shared logic for
[Umbraco Search Manager](https://www.nuget.org/packages/Umbraco.Community.SearchManager): index
and explore sources, filters, the search syntax parser, the Lucene compiler and the rebuild queue.
It references no Umbraco packages.

You do not need to install it yourself: Umbraco Search Manager brings it in. Reference it directly
only to add a search source of your own.
